🚀 About the Project

StudySphere is a modern, lightweight academic productivity toolkit designed to make student life easier.

Instead of switching between multiple apps, students can manage their academic calculations, attendance and study sessions in one beautifully designed interface.

<p align="center">
  <strong>Study smarter. Stay organized. Achieve more.</strong>
</p>⚡ Features

Feature| Description
🎓 CGPA Calculator| Calculate CGPA using subject credits and grade points.
📊 Attendance Planner| Calculate attendance percentage and plan future classes.
⏱️ Focus Timer| Stay productive with 15, 25 and 45-minute sessions.
🌙 Dark Mode| Switch between light and dark themes.
💾 Local Storage| Keep saved subjects and preferences in your browser.
📱 Responsive Design| Works across mobile, tablet and desktop screens.

🎨 Design & Experience

- Modern gradient-inspired visual identity.
- Beautiful typography using Sora and Nunito Sans.
- Smooth interface transitions and animations.
- Glass-inspired interface elements.
- Interactive navigation and controls.
- Accessible keyboard navigation.

💻 Run Locally

Clone the repository:

git clone https://github.com/surjya2007/studysphere.git

Open the project folder:

cd studysphere

Open "index.html" in your browser.

No frameworks or package installations are required.
